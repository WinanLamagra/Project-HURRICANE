# Заставка Project "Hurricane"

**Целевая длительность:** 5–7 секунд.  
**Формат:** 1080×1920, 9:16.  
**Задача:** короткая узнаваемая телевизионная идентификация, которую можно использовать в больших выпусках и иногда в коротких роликах.

## Раскадровка

| Время | Изображение | Звук |
|---|---|---|
| 0:00–0:01 | Чёрный экран, короткая вспышка телевизионного шума | Щелчок включения, шум эфира |
| 0:01–0:02 | Быстрый коллаж: винил, плата, московская улица, двигатель | Оригинальный скретч |
| 0:02–0:04 | Появляется вордмарк PROJECT HURRICANE | Короткий хип-хоповый музыкальный удар |
| 0:04–0:05 | Штамп «СБОРКА 01» и номер выпуска | Кассетный щелчок или короткий тон |
| 0:05–0:07 | Резкий переход в первый кадр истории | Музыка основного выпуска |

## Правила
- Не растягивать заставку: зритель должен быстро попасть в историю.
- Для коротких роликов использовать сокращённую версию 0,5–1 секунду или вообще обходиться без заставки.
- Создать тихую и громкую версии звука.
- Не использовать чужие музыкальные семплы без лицензии.
- Заставка должна быть модульной: можно менять номер сезона и выпуска без пересборки всей анимации.

## Вариант короткой отбивки
Один кадр вордмарка, короткий скретч и номер рубрики. Длительность до одной секунды.
